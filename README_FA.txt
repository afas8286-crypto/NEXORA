NEXORA — نسخهٔ گروه‌محور مخصوص کار و فناوری پایه نهم

قابلیت‌ها:
- ایده‌های ساختنی فقط برای استفاده در گروه‌های کلاسی
- ثبت گروه، اعضا، پروژه، تقسیم وظایف و وضعیت
- راهنمای پروژه با مراحل ساخت و آزمایش
- قالب گزارش کار و ثبت گزارش برای بررسی
- نمای آزمایشی بررسی گزارش و ثبت بازخورد معلم
- ذخیرهٔ محلی اطلاعات در مرورگر

مهم:
این نسخه هنوز حساب کاربری واقعی، ورود امن، پایگاه داده یا ارسال اینترنتی ندارد. بخش معلم و ثبت گزارش فقط روی همان مرورگر نمونه‌سازی شده‌اند و نباید به‌عنوان سامانهٔ آنلاین واقعی استفاده شوند. برای مشترک شدن اطلاعات بین گوشی‌های دانش‌آموزان و معلم، باید سرور و پایگاه داده راه‌اندازی و بخش ورود امن پیاده‌سازی شود.
