NEXORA — نسخهٔ توسعه‌یافتهٔ اولیه
=================================

فایل‌های اصلی
-------------
- index.html / style.css / app.js : رابط کاربری واکنش‌گرا؛ صفحهٔ دانش‌آموز و پنل نمایشی معلم
- server.js : سرور Node.js + Express با API حساب‌ها، پروژه‌ها، تکالیف، سؤال‌های معلم، بازخورد، اعلان‌ها و سلامت سرویس
- package.json : وابستگی‌ها و فرمان‌های اجرا
- .env.example : نمونهٔ متغیرهای محیطی (مقادیر واقعی را در آن قرار نده و منتشر نکن)
- .gitignore : جلوگیری از انتشار فایل‌های حساس و پایگاه داده

اجرای محلی با Node.js 20 یا جدیدتر
----------------------------------
1) پوشه را استخراج کن.
2) در محیطی که فرمان Node/npm دارد، داخل پوشه اجرا کن: npm install
3) برای آزمایش محلی، متغیر SESSION_SECRET را تنظیم کن؛ در محیط انتشار، NODE_ENV=production و SESSION_SECRET و ADMIN_API_KEY تصادفی و طولانی را در تنظیمات Environment میزبان قرار بده.
4) npm start
5) آدرس محلی نمایش‌داده‌شده را باز کن. برای دسترسی از اینترنت، باید روی یک میزبان واقعی منتشر شود.

نکتهٔ مهم برای کار با گوشی اندروید:
باز کردن index.html به‌تنهایی فقط رابط نمایشی را اجرا می‌کند؛ API و حساب‌های آنلاین بدون اجرای server.js و نصب وابستگی‌ها فعال نمی‌شوند. می‌توان پروژه را از گوشی در یک محیط میزبانی آنلاین منتشر کرد، اما تنظیمات سرور را باید در پنل همان میزبان انجام داد.

وضعیت فعلی و محدودیت‌ها
-----------------------
- پنل معلم داخل رابط کاربری فعلی «دمو» است و اطلاعاتش در مرورگر همان دستگاه ذخیره می‌شود. API سمت سرور برای تکالیف، سؤال‌ها، بررسی پروژه‌ها و ثبت بازخورد نوشته شده، اما هنوز فرم‌های نمایشی به API متصل نشده‌اند.
- API ثبت‌نام فقط نقش دانش‌آموز می‌دهد. تبدیل حساب به معلم از مسیر مدیریتی سرور و با ADMIN_API_KEY انجام می‌شود؛ این کلید را هرگز در مرورگر یا مخزن عمومی قرار نده.
- حساب، پروژه، تکلیف و بازخورد آنلاین فقط وقتی فعال‌اند که سرور و پایگاه داده راه‌اندازی شوند. این بسته هنوز روی دامنهٔ عمومی منتشر نشده است.
- آپلود PDF/عکس، گروه‌های زنده، آزمون آنلاین خودکار، اتصال هوش مصنوعی NEX، بازیابی رمز، ایمیل تأیید، CSRF token اختصاصی، پایگاه دادهٔ مدیریت‌شده و ذخیره‌سازی فایل ابری هنوز تکمیل نشده‌اند.
- بخش آزمون دانش‌آموز: انتخاب درس/فصل و اجرای آزمون از سؤال‌های موجود در بانک؛ در نسخهٔ فعلی فقط چند نمونهٔ تمرینی محدود وجود دارد. همچنین می‌توان سؤال‌های خود دانش‌آموز را هر خط با قالب «سؤال | پاسخ صحیح» وارد کرد. پاسخ‌نامه پس از پایان نشان داده می‌شود؛ پاسخ تشریحی خودکار نمره‌گذاری نمی‌شود تا نمرهٔ اشتباه تولید نشود.
- بانک سؤال کامل نیست. موارد دارای برچسب «نمونه تمرینی» مثال‌های آموزشی هستند و نباید سؤال امتحان واقعی معرفی شوند. فایل‌های آرشیوی باید از نظر صحت سال/ناحیه، پاسخ‌نامه و مجوز استفاده جداگانه بررسی شوند.

امنیت و پایداری
---------------
- از HTTPS در انتشار عمومی استفاده کن.
- SESSION_SECRET و ADMIN_API_KEY قوی، متفاوت و محرمانه باشند.
- قبل از انتشار، npm audit و آزمون‌های امنیتی را اجرا کن و نسخه‌های وابستگی‌ها را به‌روز نگه دار.
- این پروژه هنوز ممیزی امنیتی مستقل نشده و نباید فعلاً برای اطلاعات حساس یا نمره‌های واقعی دانش‌آموزان استفاده شود.
- برای داده‌های مهم، از پایگاه دادهٔ مدیریت‌شده، نسخهٔ پشتیبان رمزگذاری‌شده و آزمون دوره‌ای بازیابی استفاده کن. هیچ سروری نمی‌تواند ماندگاری همیشگی را تضمین کند.
